INTERACTIVE / RELIABILITY LAB

Small errors compound. Gates change the math.

A deliberately simple probability model. It assumes independent steps and a detector with fixed sensitivity; real agent failures are correlated, heterogeneous, and affected by retry policy. Use it to build intuition, not predict production performance.

What changes task-level reliability?

Baseline probability that all sequential steps succeed is pⁿ. A verification-and-recovery layer can catch a fraction of failed steps and recover some of them, at extra cost. It does not make independent errors realistic; it makes their compounding visible.
