# Why is gravity so weak?

A static, dependency-free teaching experiment. Open `index.html` or serve the repository root. All state is ephemeral in the browser. There are no remote requests from the experiment, analytics, cookies, accounts or saved quiz answers.

## Approach

Six ideas start with an everyday observation before introducing formal terms. The illustrations compress dimensions and are not numerical solutions of Einstein's equations. The warp lab evaluates exp(-x) for x=kL, and displays its square separately. It does not plot a graviton wavefunction or assert a universal force ratio. Detailed source links and scope caveats appear in the page.

## Design review

A two-model Arena comparison was used to critique the map-scale analogy against a leaking-beam analogy. Both favored the changing-scale explanation. Their output was treated as critique, not physics evidence; the primary paper and reviews own factual claims. The coding run did not produce files.
